# Python Calculator App 🧮

A modern desktop calculator built using Python and Tkinter.

## Features
- Standard Calculator
- Scientific Calculator
- Calculation History
- Dark Theme UI
- Keyboard Support
- DEG/RAD Mode
- Safe Math Evaluation

## Technologies Used
- Python
- Tkinter
